# SW-AyLP-APE-06-Arreglos-y-Listas
Este repositorio contiene el desarrollo de la actividad práctica **APE-06**, enfocada en la implementación, manipulación y análisis de estructuras de datos lineales: **Arreglos** (vectores/matrices) y **Listas** (dinámicas/enlazadas).

## 📁 Estructura del Proyecto

El proyecto está organizado de la siguiente manera:

*   **`Códigos/`**: Contiene los archivos de código fuente con las soluciones e implementaciones de los ejercicios.
*   **`Capturas/`**: Incluye imágenes y capturas de pantalla que demuestran el correcto funcionamiento y salida de los programas ejecutados.
*   **`LÉAME.md`**: Este archivo, que sirve como documentación general del repositorio.
